# WCAG 2.2 AA manual review sheet

Automation catches only reliably machine-testable failures. A named human must complete this sheet at 390 px and 1440 px, in light and dark themes where available, before claiming a manual accessibility review.

| Check | Required evidence | Status |
|---|---|---|
| Keyboard order, visible focus, menus, dialogs, and no keyboard trap | Tester, date, routes, viewport, result | Not yet performed for P1 |
| 200% and 400% zoom/reflow without lost content or two-axis reading | Screenshots/notes by route | Not yet performed for P1 |
| Text and non-text contrast, including focus and status indicators | Measured colors and exceptions | Not yet performed for P1 |
| Headings, landmarks, link purpose, form labels/errors, and status announcements | Screen-reader/browser notes | Not yet performed for P1 |
| Image purpose, captions, credit, alt text, and decorative-image treatment | Asset IDs and reviewer decision | Not yet performed for P1 |
| Bengali/Hindi pronunciation, reading order, line height, and truncation | Native-language reviewer notes | Not yet performed for P1 |
| Target size, pointer gestures, drag alternatives, and obscured focus | Tester notes at both viewports | Not yet performed for P1 |
| Motion, animation, time limits, and `prefers-reduced-motion` | OS/browser result | Not yet performed for P1 |

Automated axe, HTML, keyboard-contract, and build checks supplement this sheet but do not complete it. Screenshot baselines detect stable layout changes; they are not editorial approval, semantic review, or proof of visual truth.
