# Student Hub roadmap

Student Hub remains inactive until Jobs and Schemes have a stable publishing cadence, review ownership and measurable source quality.

Recommended sequence:

1. Scholarships
2. Entrance examinations
3. Admissions and counselling
4. Results
5. Courses and degrees
6. Career guidance
7. School, college and university information

Before activating each section, add its structured fields in a reversible migration, public schema validation, search filters, editorial owner, verification checklist, at least a small reliable content library and translated policy/UI copy. Do not expose an empty navigation item merely because the database supports it.
