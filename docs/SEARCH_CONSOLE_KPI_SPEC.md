## Editorial dashboard specification

- Trust: named writer/reviewer coverage, primary-source support, partial-confirmation reason/age, corrections and withdrawals.
- Freshness: overdue reviews, expired active records, broken/redirected official links and median source-check age by beat.
- Output: distinct stories—not translations—by beat/authority/state, translation share/turnaround and notice-to-publication time.
- Automation: each outcome count, acceptance/rejection reason and accepted-draft usefulness rate.
- Audience: Search Console clicks/impressions/CTR/position first; approved product events only after the privacy gate.
- Operations: deployment health, incident/restore evidence and unresolved owner blockers.

Every chart needs a definition, source, owner, reporting period and missing-data state. Empty data is shown as unavailable, never zero. A dashboard specification is not an operating SEO loop until real weekly decisions are recorded.
