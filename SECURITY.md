# Security policy

## Reporting a vulnerability

Email **citizenaffairs.in@gmail.com** with the subject `Private security report — Citizen Affairs`. Include the affected URL or file, impact, reproduction steps, and the least sensitive proof needed to verify the issue.

Do not open a public issue for an unpatched vulnerability, publish secrets or personal data, test against people, submit destructive traffic, or attempt to access data that is not yours. No attachment is required; send a safe text description or private link if evidence is necessary.

The current public site is static and has no public account, payment, upload, or form-processing endpoint. Reports about repository automation, deployment, dependencies, DNS, impersonation, or misleading public information are still in scope.

Receipt and resolution targets are defined by severity in [docs/CORRECTIONS.md](docs/CORRECTIONS.md). They are operating targets, not a bounty promise or guarantee. A real security-response drill and additional emergency administrator remain owner actions.

## Supported version

Security fixes apply to the current production branch. Historical commits and unpublished local branches are not separately supported.
