Pages CMS now separates private drafts from articles that are already live. Drafts stay editable; live articles are shown in a view-only section so their publication state is unmistakable.

  1. 🟡 Draft articles — NOT LIVE. Review and edit generated or manually prepared drafts here.
  2. 🟢 Live articles — PUBLISHED. Use this section to confirm which articles are already public.
  3. Protected publication remains separate. Moving from draft to live still requires the existing approval and publication workflow.

A draft is not public merely because it appears in Pages CMS. Only articles in the green Live section are intended to be publicly available.
