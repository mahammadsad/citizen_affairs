# Draft-only citizen-service templates

These six templates are starting contracts, not publishable articles. Copy one into `src/content/articles/<language>/drafts/`, replace every angle-bracket instruction with current official evidence, and keep it private until independent human review is recorded.

Every template deliberately sets `draft: true`, `workflowStatus: draft`, `verificationStatus: under-verification`, `independentReviewStatus: not-assigned`, and `checkBeforeActing: true`. Automation or an author must not change those publication controls.

Before review, confirm the issuing authority, exact notice/order, dates, geography, eligibility, fees, current status, later corrigenda and official action URL. Delete fields that genuinely do not apply; never invent a value to fill the template.
