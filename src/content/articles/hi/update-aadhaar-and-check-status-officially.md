Aadhaar में address, mobile number, supporting documents, demographic details और biometrics एक ही तरीके से update नहीं होते। UIDAI अभी अलग-अलग services **myAadhaar portal**, official **Aadhaar app** और authorised **Aadhaar Enrolment या Update Centres** के माध्यम से देता है।

पुरानी guidance में mobile-number update को centre-only बताया जाता था। UIDAI की current 2026 guidance के अनुसार official Aadhaar app कुछ cases में existing registered mobile number बदलने की सुविधा देता है। First-time mobile registration, पुराने registered number की access न होना, biometric update और कुछ demographic corrections के लिए authorised centre अभी भी आवश्यक है।

**Citizen Affairs UIDAI या किसी Aadhaar centre का हिस्सा नहीं है।** Services, fees, accepted documents और interface बदल सकते हैं। Submit या payment करने से पहले current UIDAI screen और instructions जाँचें।

## 1. केवल official Aadhaar channels उपयोग करें

- myAadhaar portal: [myaadhaar.uidai.gov.in](https://myaadhaar.uidai.gov.in/)
- UIDAI information website: [uidai.gov.in](https://uidai.gov.in/en/updating-data-on-aadhaar)
- Official Aadhaar app का link UIDAI website या verified app-store listing से लें;
- Centre locator या appointment link UIDAI की official pages से ही खोलें।

Search advertisement, forwarded link, clone website, unknown APK और agent की personal link से बचें। OTP, app PIN, password, Face Authentication access या payment credential किसी को न दें।

## 2. myAadhaar पर उपलब्ध services

UIDAI की current online guidance में सामान्यतः ये services शामिल हैं:

- address update;
- Proof of Identity और Proof of Address document update;
- update request status tracking;
- e-Aadhaar download और अन्य authenticated services।

OTP-based login और submission के लिए Aadhaar से linked registered mobile number आवश्यक है।

### Address update के सामान्य steps

1. Aadhaar number और registered-mobile OTP से myAadhaar में sign in करें।
2. Address-update service चुनें।
3. Current accepted-document list से valid Proof of Address चुनें।
4. Document के अनुसार address ठीक-ठीक भरें।
5. English और local-language preview ध्यान से देखें।
6. Clear colour scan या image upload करें।
7. Portal current fee दिखाए तो केवल official payment flow से pay करें।
8. Invoice या acknowledgement download करके SRN सुरक्षित रखें।

Submission approval की guarantee नहीं है। UIDAI verification और validation के बाद request process करता है।

## 3. POI और POA document update

UIDAI Aadhaar holders को identity और address documents current रखने की सलाह देता है, जिसमें supporting documents को कम-से-कम दस वर्ष में एक बार update करना शामिल है। Document update demographic value बदलने से अलग है; इसका उद्देश्य Aadhaar record के साथ current POI और POA बनाए रखना है।

UIDAI के current FAQ के अनुसार:

- myAadhaar से document submission **14 June 2027 तक free** है;
- Aadhaar centre पर document update की current fee ₹75 है;
- deadline और fee बदल सकती है, इसलिए submission date पर current notice देखें।

Upload से पहले सुनिश्चित करें कि:

- document UIDAI की current accepted list में है;
- holder का नाम match करता है;
- entered address POA document से agree करता है;
- image clear, coloured और readable है;
- document expired, altered या incomplete नहीं है।

## 4. Official Aadhaar app से address update

UIDAI की current Aadhaar app guidance में app registration, document upload, address preview, Face Authentication और prescribed charge वाला address-update flow बताया गया है। Registered mobile और SIM situation के अनुसार OTP flow अलग हो सकता है।

पुराने video के बजाय current app screen के प्रत्येक label को पढ़ें। केवल official app उपयोग करें और किसी दूसरे व्यक्ति को Face Authentication या account access control न दें।

## 5. App से existing mobile-number update

Supported cases में official Aadhaar app existing registered mobile number बदलने की अनुमति दे सकता है। Process में access checks, OTP, Face Authentication और displayed charge का payment लग सकता है।

Authorised centre तब भी आवश्यक है जब:

- mobile number पहली बार register करना हो;
- पुराने registered mobile number की access न हो;
- app required flow न दिखाए;
- UIDAI user को enrolment या update centre पर जाने को कहे।

Biometric, OTP या identity checks bypass करने का दावा करने वाले agent को payment न करें।

## 6. कौन-से updates के लिए centre आवश्यक होता है

Authorised Aadhaar centres सामान्यतः इन services के लिए आवश्यक रहते हैं:

- first-time mobile registration या पुराने number की access न होने पर recovery;
- biometric updates;
- current UIDAI rules के अनुसार कई name, date-of-birth, gender या अन्य demographic corrections;
- वे requests जो online या app से complete नहीं हो सकतीं।

UIDAI का official centre locator या appointment system उपयोग करें। Current service charge UIDAI या authorised centre पर देखें और receipt लें।

## 7. SRN या acknowledgement से request track करें

Online submission के बाद Service Request Number, invoice और acknowledgement सुरक्षित रखें। Official myAadhaar status facility से progress track करें।

Outcome processing, approval या rejection हो सकता है। Rejection reason पढ़ें और document या data सही करके ही दोबारा submit करें। Match कराने के लिए official document edit न करें।

Centre-based update के लिए acknowledgement slip और उस पर दिया Update Request Number या अन्य identifier सुरक्षित रखें।

## 8. Aadhaar information सुरक्षित रखें

- OTP, UPI PIN, app PIN या password कभी साझा न करें।
- Message से मिला APK install न करें।
- Aadhaar transaction के दौरान screen sharing या remote-access control न दें।
- Public screenshot से sensitive numbers mask करें।
- संभव हो तो private device उपयोग करें और काम के बाद logout करें।
- Cyber café या shared device से downloaded documents delete करें।

Professional-looking page, UIDAI logo या `https` padlock अकेले authenticity साबित नहीं करते।

## अंतिम checklist

Update submit करने से पहले सुनिश्चित करें कि आपने:

- update type के लिए सही official channel चुना है;
- current accepted-document list देखी है;
- documents के अनुसार information भरी है;
- local-language preview जाँचा है;
- payment केवल authorised route से किया है;
- SRN, invoice या centre acknowledgement सुरक्षित रखा है;
- UIDAI की official service से status check किया है।

Services, fees और supported update methods बदल सकते हैं, इसलिए current UIDAI instructions को final authority मानें।
