## शुरू करने से पहले

यह मार्गदर्शिका पहले से जमा अनुरोध के लिए है। online service या enrolment centre से मिली रसीद पास रखें। उस पर दिया reference number आधिकारिक system को आपका अनुरोध खोजने में मदद करता है।

अचानक आए call या message में किसी को OTP, Aadhaar number या पहचान दस्तावेज़ की copy न दें। स्थिति और अगले कदम के लिए UIDAI अंतिम प्राधिकरण है।

## चरणबद्ध प्रक्रिया

1. इस पृष्ठ के आधिकारिक link से myAadhaar portal खोलें।
2. enrolment या update status जाँचने का विकल्प चुनें। इस्तेमाल की गई सेवा के अनुसार उसका नाम थोड़ा अलग हो सकता है।
3. screen पर माँगा गया Enrolment ID, Service Request Number या Update Request Number भरें।
4. आधिकारिक portal माँगे तो security check या OTP verification पूरा करें।
5. दिखाई गई स्थिति पढ़ें और reference number अपने record के लिए सुरक्षित रखें।
6. कोई अतिरिक्त कदम बताया जाए तो पहले देखें कि निर्देश UIDAI domain पर ही है।

## परिणाम समझना

अनुरोध submitted, review में, completed या rejected दिख सकता है। UIDAI portal बदलने पर exact label भी बदल सकता है। पूरा होने पर UIDAI की आधिकारिक download या संबंधित सेवा इस्तेमाल करें। अस्वीकार होने पर दिखाए कारण के आधार पर तय करें कि नया अनुरोध जरूरी है या नहीं।
